# タスクの状態管理

- タスクを担当するエージェントは、作業に伴うタスクの状態更新に責任を持つ（MUST）。
- 実装を開始する前に、対象タスクを「進行中」相当へ更新する（MUST）。
- 実装・検証が完了し、PRを作成または更新したら、対象タスクを「レビュー中」相当へ更新する（MUST）。
- PRをマージしたら、完了条件を満たす対象タスクを「完了」相当へ更新する（MUST）。
- 更新後は、トラッカー上で期待する状態になったことを確認する（MUST）。自動更新の場合も確認し、既に期待する状態であれば更新は不要とする。
- 更新できない場合は、理由と現在の状態を報告する（MUST）。

## トラッカーの確認

- 対象タスクがある場合、リポジトリの README の `task_tracker: <name>` 宣言でトラッカーを確認する（MUST）。宣言がなければユーザーに確認し、導入済みの CLI や接続中の MCP から推測しない（NEVER）。回答後は README への宣言追加を提案する（SHOULD）。
- 状態名はトラッカーの既存設定に従う。対応する状態がなければ報告し、フィールド・ラベル・列を独自に作成しない（MUST）。
