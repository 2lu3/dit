# 基本概念

## 実体とポインタ

実体は計算で使用する大容量ファイル本体です。Gitには保存せず、S3互換remoteへ転送します。ポインタは `*.dit` ファイルで、実体のパス、ハッシュ、サイズを記録し、Gitで共有します。

## remote

remoteは `dit.toml` のbucketとprefixで指定します。認証情報とendpointは環境変数から読み取ります。

## scope

scopeは、このマシンで実体を置くディレクトリの集合です。ディレクトリを指定しない場合はリポジトリ全体がscopeになります。`dit add` と `dit push` はscopeに関係なく実体を登録・アップロードします。`dit pull` はscope内の実体を取得します。`dit sync` はscope内を同期し、復元可能なscope外の実体を削除します。

そのため、同じGitリポジトリを複数マシンで共有しながら、マシンごとに必要なデータだけを保持できます。[scopeの使い方](scopes.md)も参照してください。

## 同期

scope内にポインタと実体がある場合、ditは内容の一致を確認し、必要に応じてpushまたはpullします。ポインタだけがある場合はremoteから実体を取得します。実体だけがある場合は、先にポインタを作成する必要があります。
