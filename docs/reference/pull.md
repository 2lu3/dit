# `dit pull`

欠落しているオブジェクトを scope 内からダウンロードする.

転送中はバイト量を Kbyte / Mbyte / Gbyte の N/N で表示する.

```console
$ dit pull [OPTIONS]
```

## Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---:|---|---|
| `--dry-run` | boolean | no | false | 実行せずに予定だけ表示する |
| `--help` | boolean | no | false | Show this message and exit. |
