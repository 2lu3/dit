# `dit add`

Scope 内の追跡パスのポインタを作成・更新する.

```console
$ dit add [OPTIONS]
```

## Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---:|---|---|
| `--quiet`, `-q` | boolean | no | false | 詳細出力を抑える |
| `--prune` | boolean | no | false | scope 内の不要ポインタを削除する |
| `--help` | boolean | no | false | Show this message and exit. |
