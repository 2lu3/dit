# `dit push`

scope に関係なくポインタが指すローカルオブジェクトをアップロードする。実体とポインタが異なる場合は `dit add` が必要です。

転送計画中はポインタ一覧の作成中にスピナーを表示し、各ポインタの確認数を進捗表示する。対象確定後の転送中はバイト量を Kbyte / Mbyte / Gbyte の N/N で表示する.

ローカルのハッシュ確認には `.dit/index.db` を使う。更新日時・変更時刻（ctime）・サイズ・inode が前回と一致すればハッシュを再利用し、未記録または変更時だけ再計算する。既存 DB は自動移行する。送信直前にもファイル情報を確認し、計画後の変更を検出した場合は再計算してポインタと照合する。

リモートでの存在確認は、対象 prefix のオブジェクト一覧を全ページ取得して一括照合する。S3 では `s3:ListBucket` 権限が必要。一覧取得に失敗した場合はエラーにし、未保存と見なして送信することはない。

全パスを確認したうえで、同じハッシュのファイルは代表の1パスを表示し、一度だけ送信する。複数ファイルを並列にアップロードし、ファイル内の分割転送も含めて `DIT_TRANSFER_CONCURRENCY` の上限を共有する（既定値16）。並列実行中に失敗した場合は、新たなファイルの送信を止めてエラーを返す。再実行すると保存先を再確認し、未保存の内容だけを送信する。

```console
$ dit push [OPTIONS]
```

## Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---:|---|---|
| `--dry-run` | boolean | no | false | 実行せずに予定だけ表示する |
| `--help` | boolean | no | false | Show this message and exit. |
